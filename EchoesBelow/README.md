# Game Project

This folder contains the game-specific content Echoes Below.

## Structure

- **Assets/** - Game assets (scenes, prefabs, textures, audio, shaders)
  - **Scenes/** - Scene files (.scn)
  - **Prefabs/** - Prefab files (.prefab)
  - **Textures/** - Game textures
  - **Audio/** - Game audio files
  - **Shaders/** - Custom shaders
- **Scripts/** - Game C# scripts (.csproj and .cs files)
- **ProjectSettings.json** - Game configuration

## Getting Started

1. Open the editor: Run `GrapeEngine.exe` from the build directory
2. Create a new scene: File -> New Scene
3. Save to: `GameProject/Assets/Scenes/YourScene.scn`
4. Create scripts in `GameProject/Scripts/`
5. Configure startup scene in `ProjectSettings.json`

## Note

This folder structure is temporary until the editor is separated from the engine repository.
