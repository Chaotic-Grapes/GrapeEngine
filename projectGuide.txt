================================================================================
                            GRAPEENGINE PROJECT GUIDE
================================================================================

This guide will help you set up the development environment and build the 
GrapeEngine project from scratch.

================================================================================
PREREQUISITES
================================================================================

1. VISUAL STUDIO 2022
   - Download: https://visualstudio.microsoft.com/downloads/
   - Install "Desktop development with C++" workload
   - Ensure **C++23** support is available

2. GIT
   - Download: https://git-scm.com/downloads
   - Required for cloning the repository (including third-party libraries)

3. CMAKE 3.13+
   - Download: https://cmake.org/download/
   - Required for building

4. .NET 9 SDK
   - Download: https://dotnet.microsoft.com/en-us/download/dotnet/9.0
   - Required for scripting

5. DOXYGEN
   - Download: https://www.doxygen.nl/download.html
   - Optional, but required for documentation

================================================================================
STEP 1: INSTALL CMAKE (Build System)
================================================================================

  CMAKE 3.13 or later is required to generate the Visual Studio solution files.

OPTION A: Download from Official Website (Recommended)
----------------------------------------------------------
1. Go to: https://cmake.org/download/
2. Download "Windows x64 Installer" (cmake-X.XX.X-windows-x86_64.msi)
3. Run the installer
4. IMPORTANT: During installation, select "Add CMake to the system PATH for all users"
5. Complete the installation

OPTION B: Using Visual Studio Installer
----------------------------------------
1. Open Visual Studio Installer
2. Modify your Visual Studio 2022 installation
3. Go to "Individual components" tab
4. Search for "CMake tools for Visual Studio"
5. Check the box and install

OPTION C: Using Chocolatey (if you have it installed)
-----------------------------------------------------
1. Open PowerShell as Administrator
2. Run: choco install cmake

VERIFICATION:
-------------
Open Command Prompt or PowerShell and run:
    cmake --version

You should see output like: cmake version 3.XX.X

PREMAKE (N.A.)
-------------------------------
This project uses CMake and does not provide Premake files. You do not need Premake.

================================================================================
STEP 2: CLONE THE REPOSITORY
================================================================================

1. Open Command Prompt or PowerShell
2. Navigate to your desired directory:
   cd C:\YourProjects\

3. Clone the repository:
   git clone https://github.com/Chaotic-Grapes/GrapeEngine.git

4. Navigate to the project directory:
   cd GrapeEngine

================================================================================
STEP 3: GENERATE VISUAL STUDIO SOLUTION
================================================================================

METHOD 1: Using the Batch Files (Recommended)
---------------------------------------------
1. In the GrapeEngine directory, run:
   run.bat

`run.bat` will:
- Configure the editor build in `build\`
- Build Editor Debug (`build\Debug`)
- Build Editor Release (`build\Release`)

METHOD 2: Manual CMake Commands
-------------------------------
1. Open Command Prompt or PowerShell in the GrapeEngine directory

2. Create and enter build directory:
   mkdir build
   cd build

3. Generate Visual Studio solution:
   cmake .. -G "Visual Studio 17 2022" -A x64

4. (Optional) Build from command line:
   cmake --build . --config Debug

================================================================================
STEP 4: OPEN AND BUILD IN VISUAL STUDIO
================================================================================

1. Navigate to the 'build' directory in your file explorer
2. Double-click 'GrapeEngine.sln' to open in Visual Studio 2022
3. Set the build configuration to 'Debug' and platform to 'x64'
4. Right-click the 'GrapeEngine' project in Solution Explorer
5. Select 'Set as StartUp Project'
6. Press F5 or click 'Local Windows Debugger' to build and run

================================================================================
STEP 5: RUNNING THE EDITOR
================================================================================

OPTION A: From Visual Studio
----------------------------
- Press F5 to run with debugging
- Press Ctrl+F5 to run without debugging

OPTION B: Using run.bat
-----------------------
 - Run: run.bat
 - Then run the editor executable from `build\Debug\` or `build\Release\`

OPTION C: Direct Execution
--------------------------
- Navigate to: build\Debug\
- Run: GrapeEngine.exe

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "cmake is not recognized as an internal or external command"
SOLUTION: CMake is not in your PATH. Reinstall CMake and ensure you select
          "Add CMake to the system PATH" during installation.

PROBLEM: "Visual Studio 17 2022" generator not found
SOLUTION: Ensure Visual Studio 2022 is installed. You can also try:
          cmake .. -G "Visual Studio 16 2019" -A x64

PROBLEM: Build errors related to missing dependencies
SOLUTION: Ensure all submodules are initialized:
          git submodule update --init --recursive

PROBLEM: "MSBuild version X.X not found"
SOLUTION: Install or repair Visual Studio 2022 with C++ development tools.

================================================================================
ADDITIONAL COMMANDS
================================================================================

CLEAN BUILD:
- Run: clean.bat (removes `build` and `build_game` directories)
- Or manually delete generated build folders

REGENERATE SOLUTION:
- Delete the 'build' folder
 - Run run.bat again
- Or use the manual CMake commands above

PROJECT STRUCTURE
================================================================================
  
└── GrapeEngine/
   ├── assets/         # Shared engine assets (textures, shaders, etc.)
   ├── build/          # Editor build output (generated)
   ├── build_game/     # Standalone game export output (generated)
   ├── cmake/          # CMake modules and configuration
   ├── editor/         # Editor source and headers
   ├── engine/         # Engine source and headers
   ├── externals/      # Third-party dependencies
   ├── managed/        # C# scripting and tools
   ├── runtime/        # Runtime assets/binaries for game export
   ├── TestSuite/      # Sample project (To add in editor for testing)
   ├── CMakeLists.txt  # Main CMake configuration
   ├── run.bat         # Configure/build editor (Debug + Release)
   └── clean.bat       # Remove generated build folders

================================================================================
PROJECT SETTINGS AND CONFIGURATION
================================================================================

BUILD CONFIGURATIONS
--------------------

The GrapeEngine supports two main build configurations:

1. DEBUG CONFIGURATION
   - Executable location: build\Debug\GrapeEngine.exe
   - Includes debug symbols and assertions
   - Optimizations disabled for easier debugging
   - Additional logging and error checking enabled

2. RELEASE CONFIGURATION
   - Executable location: build\Release\GrapeEngine.exe
   - Optimized for performance
   - Debug symbols stripped
   - Minimal logging for better performance

To switch between configurations in Visual Studio:
- Use the dropdown in the toolbar to select "Debug" or "Release"
- Rebuild the solution after changing configurations

TARGETS (Editor vs Standalone Game)
-----------------------------------

The project produces two targets:
- Editor: interactive level editor, built into `build\Debug` / `build\Release`
- Standalone Game: gameplay-only executable, built into `build_game\export\<ProjectName>\<Config>`

How to select targets:
- Use `run.bat` to configure and build the Editor in both Debug and Release
- Use Visual Studio or direct executable launch to run the desired Editor config
- In Visual Studio, open the solution in 'build\' and run the Editor

APPLICATION CONFIGURATION (EditorSettings.json / ProjectSettings.json)
---------------------------------------------------------------------

Editor and project configuration are stored in the user Documents folder:
- Editor settings (recent projects, window/UI options):
  Documents\Grape Engine\EditorSettings.json
- Project settings (per-project runtime options):
  Documents\Grape Engine\<ProjectName>\ProjectSettings.json

Notes:
- The editor writes these files automatically. If they are missing, defaults
  are created on first run.
- Game export copies ProjectSettings.json into the export output so the
  standalone build uses the project-specific settings.

TROUBLESHOOTING:
- If settings are not loading, verify the Documents folder is writable and
  the project name matches the folder under Documents\Grape Engine.

LEVEL EDITOR MODES
------------------

Real-time Editor (recommended):
- Run the Editor target from Visual Studio or by launching `build\Debug\GrapeEngine.exe` / `build\Release\GrapeEngine.exe`
- Use the playback toolbar (Play/Pause/Stop) to control simulation

Turn Editor Off (gameplay-only):
- Run the Standalone Game target executable directly (no editor overlay)
- Alternatively, close the editor and run the game exe from 'build_game\Debug\' or 'build_game\Release\'

Offline Editing:
- Use the Editor to edit scenes/prefabs without pressing Play; save changes to JSON
- Scenes/prefabs are deserialized at runtime, so no recompilation is needed

TROUBLESHOOTING CONFIGURATION ISSUES
------------------------------------

Config File Not Found:
- Ensure config.json exists in the same directory as the executable
- Copy config.json from project root to build/Debug/ or build/Release/
- Check that the JSON syntax is valid

Build Configuration Issues:
- Verify the correct configuration (Debug/Release) is selected
- Clean and rebuild the solution if switching configurations
- Check that all dependencies are properly linked

REGENERATE VISUAL STUDIO 2022 SOLUTION
--------------------------------------

Quick batch files (recommended):
- Clean: `clean.bat` (removes generated build folders)
- Rebuild solution + editor binaries: `run.bat` (creates/refreshes `build\` and builds Debug + Release)

Manual CMake:
- Regenerate Editor solution:
  1) 'mkdir build'
  2) 'cd build'
  3) 'cmake .. -G "Visual Studio 17 2022" -A x64'

Notes:
- Use 'cmake --version' to verify CMake is installed
- If generator errors occur, ensure Visual Studio 2022 and C++ workload are installed
